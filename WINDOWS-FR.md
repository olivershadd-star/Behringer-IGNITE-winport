# Windows — nouvelle base standalone

Le precedent portage et son interface sont retires de la version proposee. Son ancien workflow a ete supprime.

La nouvelle application est **IgniteStandalone.exe**, construite uniquement depuis [`Standalone/`](Standalone/README.md). Lire ce guide pour les six pistes, instruments, kits de batterie et patterns de seize pas. Le bouton PLAY lit une demonstration des le premier lancement. Aucun materiel IGNITE ou port MIDI n'est requis.
